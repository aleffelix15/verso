# Modelos 3D Procedurais

Todas as peças foram geradas e estão disponíveis para importação com as seguintes tipagens (Color/Accent personalizáveis).

## Catálogo Gerado:

```tsx
import { CamisetaOversized } from "@/components/three/models/camiseta-oversized";
// <CamisetaOversized color="#0E0E0E" accent="#E4572E" autoRotate />
// Detalhes: Torso expandido, gola em TorusGeometry, estampa 3D "LUZ"
```

```tsx
import { MoletomBoxy } from "@/components/three/models/moletom-boxy";
// <MoletomBoxy color="#0E0E0E" accent="#E4572E" autoRotate />
// Detalhes: Capuz esférico, bolso canguru, cordões salientes e texto "SALMO 23"
```

```tsx
import { Bone5Paineis } from "@/components/three/models/bone-5-paineis";
// <Bone5Paineis color="#0E0E0E" accent="#E4572E" autoRotate />
// Detalhes: Formato clássico 5-panel via Hemisfério, aba curvada e bordado "VERSO" frontal
```

```tsx
import { JaquetaCoach } from "@/components/three/models/jaqueta-coach";
```
